    Is this connected to a real backend?

    No. Everything runs in the browser with vanilla JavaScript for easy review.

    Where are my documents stored?

    Nowhere. Only the selected file names are displayed so reviewers can see the flow without uploads.

    How does status tracking work?

    Each submission gets a generated ID and starts at step 1. Click “Advance status” on a card to move it forward.

    Can I reset the sample data?
